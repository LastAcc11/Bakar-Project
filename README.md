# בקר — מערכת דוחות לבקר בטיחות באתרי בנייה

אפליקציית ווב (עובדת בטלפון ובמחשב, גם בלי קליטה) שמחליפה את מילוי טפסי ה-Word של **בקר הבטיחות**
לפי סעיף 2א' ל**תקנות הבטיחות בעבודה (עבודות בניה ובניה הנדסית), תשמ"ח-1988**.
במקום לערוך מסמך, ממלאים שאלון קצר עם כפתורים, והמערכת מפיקה את הדוח בפורמט המקורי, כ-**PDF** וכ-**Word**.

## מה המערכת עושה

- **אשף מילוי שלב אחר שלב**: לכל שורה יש כפתורי סימון (תקין/לא תקין/לא רלוונטי, ובטרום עבודה יש/אין/לא רלוונטי),
  ולכל שורה אפשר להוסיף הערה ותמונה. ההערות נכנסות אוטומטית ל"פירוט הליקויים" בדוח.
- **צילום במקום**: תמונה שמצלמים מתוך שורה או סעיף מופיעה בדוח ליד אותו סעיף. תמונות כלליות נכנסות לנספח.
- **עריכת רשימות**: בכל דוח אפשר לשנות נוסח של שורה, להסתיר שורות לא רלוונטיות ולהוסיף שורות ("✎ ערוך רשימה").
  את רשימות ברירת המחדל לדוחות הבאים קובעים בהגדרות.
- **טפסים מותאמים**: צ'ק ליסט משלך לתחומים אחרים, עם כותרת, סעיפים, פריטים ותוויות סימון שאתה קובע.
- **אתרים ואנשי קשר**: שם, ח.פ./ת.ז., נייד ומייל של המזמין, המבצע, מנהל האתר ומנהל העבודה. הפרטים נכנסים לשורת "אל" ולנתונים הכלליים.
- **מספור אוטומטי** של הדוחות לכל אתר, ו**קיבוץ הדוחות לפי מזמין** מכל האתרים שלו.
- **בלי כפילויות**: דוח חדש נשמר רק אחרי השינוי הראשון. אם כבר יש טיוטה פתוחה לאותו אתר, המערכת שואלת אם להמשיך בה.
- **תפוצה**: לכל דוח מוצגת רשימת נמענים לפי סוג הדוח: אנשי הקשר של האתר, עורך הדוח ונמענים קבועים מההגדרות
  (ואם לא הוגדרו, הנמענים האחרונים). לכל נמען יש כפתורי וואטסאפ ו-Gmail.
- **מעקב ביקורות**: שלבי חובה (חפירות, ביסוס, שלד, גמר) ותזכורת לפני שעוברים 3 חודשים מהביקור האחרון.
- **מועדי הפצה**: 48 שעות לדוח ביקור, ומיידית לסיכון בלתי קביל. "סמן כהופץ" מוריד את הדוח מרשימת הממתינים.
- **סיכון בלתי קביל**: מטריצת "לוח החלטה" אינטראקטיבית. אפשר להסתיר אותה מהדוח או לקבוע דירוג ידני.
  מליקוי בדוח ביקור פותחים בלחיצה הודעת סיכון נפרדת, מקושרת לדוח ועם התמונות שלו.
- **הפקה**: PDF וקטורי ו-Word שאפשר לערוך, עם תיבות סימון שאפשר לסמן בתוך Word. לוגו, שם חברה וסלוגן בראש כל דוח.
- **ענן ומכשיר**: התחברות עם Google או אימייל, סנכרון בין מכשירים (Firebase, בחינם) ועבודה בלי קליטה.
  אפשר לכבות את השמירה בענן בהגדרות.
- **PWA**: אפשר "להוסיף למסך הבית" ולהשתמש בזה כמו באפליקציה.

## הגדרת Firebase (פעם אחת, ב-[Firebase Console](https://console.firebase.google.com/project/bakar-project))

1. **Authentication** → Get started → **Sign-in method**: להפעיל **Email/Password** ו-**Google**.
2. **Authentication** → **Settings** → **Authorized domains**: להוסיף את הדומיין שבו האתר מתפרסם (למשל `lastacc11.github.io`).
3. **Realtime Database** → **Rules**: להדביק את התוכן של [`database.rules.json`](database.rules.json) וללחוץ Publish.
   הכללים קובעים שכל משתמש יכול לקרוא ולכתוב רק תחת `users/<המזהה שלו>`.

ההגדרות של הפרויקט נמצאות ב-[`js/firebase-config.js`](js/firebase-config.js). ה-SDK של Firebase נמצא בתיקייה `vendor/firebase` ונטען מקומית, כדי שהאפליקציה תעבוד גם אופליין.

## פרסום

**האתר פעיל בכתובת: https://bakar-reports.web.app** (Firebase Hosting)

כתובת גיבוי ב-GitHub Pages: https://lastacc11.github.io/Bakar-Project/

כל עדכון שנדחף לענף `claude/loving-euler-km4r96` מתפרסם אוטומטית בשתי הכתובות דרך
[`.github/workflows/publish.yml`](.github/workflows/publish.yml). הפרסום ל-Firebase מתחבר ל-Google בלי סיסמאות שמורות
(Workload Identity Federation): רק הריפו הזה מורשה, ורק לפרסום האתר, דרך חשבון השירות
`github-deploy@bakar-project.iam.gserviceaccount.com` עם התפקיד Firebase Hosting Admin.

פרסום ידני מהמחשב (אם צריך): `npm i -g firebase-tools`, אחר כך `firebase login`, ואז `firebase deploy --only hosting`.

## הרצה מקומית

אין שלב בנייה. כל הקבצים סטטיים.

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```


## מבנה הקוד

```
index.html            מעטפת האפליקציה
css/app.css           עיצוב הממשק (בהיר/כהה, מותאם לנייד)
css/paper.css         עיצוב דף הדוח (תצוגה מקדימה והדפסה)
js/templates.js       ← כל נוסחי הטפסים: פריטים, סעיפים, מטריצה. לשינוי נוסח עורכים רק כאן
js/model.js           בונה "מודל מסמך" אחד מהדוח
js/render-html.js     מודל → תצוגה מקדימה (HTML)
js/export-pdf.js      מודל → PDF (jsPDF + bidi + גופן עברי מוטמע)
js/export-docx.js     מודל → Word (ספריית docx)
js/app.js             ממשק, ניווט, שמירה אוטומטית
js/cloud.js           Firebase: התחברות וסנכרון לענן
js/firebase-config.js הגדרות פרויקט ה-Firebase
js/db.js              עותק מקומי במכשיר (IndexedDB) + גיבוי
js/signature.js       משטח חתימה
sw.js                 עבודה אופליין
vendor/               ספריות צד שלישי (Firebase, docx, jsPDF, bidi-js, גופן Liberation Sans, רישיון OFL)
database.rules.json   כללי האבטחה של ה-Database
firebase.json         הגדרות לפרסום ב-Firebase Hosting
```

כל שלושת הפורמטים (תצוגה, PDF ו-Word) נבנים מאותו מודל, ולכן התוכן שלהם תמיד זהה.
