# בקר — מערכת דוחות לבקר בטיחות באתרי בנייה

אפליקציית ווב (עובדת בטלפון ובמחשב, גם בלי קליטה) שמחליפה את מילוי טפסי ה-Word של **בקר הבטיחות**
לפי סעיף 2א' ל**תקנות הבטיחות בעבודה (עבודות בניה ובניה הנדסית), תשמ"ח-1988**.
במקום לערוך מסמך, ממלאים שאלון קצר עם כפתורים, והמערכת מפיקה את הדוח בפורמט המקורי, כ-**PDF** וכ-**Word**.

## מה המערכת עושה

- **אשף מילוי שלב אחר שלב**: לכל פריט יש כפתורי תקין / לא תקין / לא רלוונטי. כשמסמנים "לא תקין" נפתח שדה לפירוט,
  והפירוט נכנס אוטומטית ל"פירוט הליקויים" בדוח. כפתור "סמן את הנותרים כתקין" חוסך הקלדה.
- **אתרים**: פרטי האתר ואנשי הקשר (מזמין, מבצע, מנהל אתר, מנהל עבודה) נשמרים פעם אחת ומתמלאים בכל דוח.
- **מעקב ביקורות**: לכל אתר רואים אילו שלבים כבר נבדקו (חפירות, ביסוס, שלד, גמר), ומקבלים תזכורת כשמתקרבים ל-3 חודשים מהביקור האחרון.
- **מועדי הפצה**: דוחות שעדיין לא הופצו מוצגים עם המועד האחרון להפצה (48 שעות / מיידי).
- **הסלמה בלחיצה**: מליקוי בדוח ביקור אפשר לפתוח "הודעת סיכון בלתי קביל" שהפרטים כבר ממולאים בה.
- **מטריצת סיכון אינטראקטיבית**: מקישים על תא, ורואים מיד את הציון ואת רמת הסיכון בצבעי הלוח המקורי.
- **חתימה דיגיטלית** (באצבע או בעכבר), **לוגו חברה** בכותרת, **תמונות מהשטח** בנספח (צילום ישיר מהטלפון).
- **הפקה**: PDF וקטורי (טקסט חד שאפשר לחפש בו) ו-Word שאפשר לערוך, שניהם מימין לשמאל. בטלפון, "שיתוף" שולח את ה-PDF ישר לוואטסאפ או למייל.
- **פרטיות**: כל הנתונים נשמרים רק במכשיר (IndexedDB). אין שרת ואין חשבון. יש גיבוי ושחזור לקובץ, וכך אפשר גם להעביר נתונים בין מכשירים.
- **PWA**: אפשר "להוסיף למסך הבית" ולעבוד אופליין.

## הרצה

אין שלב בנייה. כל הקבצים סטטיים.

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

כדי לפרסם, מספיק להעלות את התיקייה לכל אחסון סטטי: GitHub Pages, Netlify, Cloudflare Pages וכדומה.
צריך HTTPS כדי שהתקנה כאפליקציה ועבודה אופליין יפעלו.

## מבנה הקוד

```
index.html            מעטפת האפליקציה
css/app.css           עיצוב הממשק (בהיר/כהה, מותאם לנייד)
css/paper.css         עיצוב דף הדוח (תצוגה מקדימה והדפסה)
js/templates.js       ← כל נוסחי הטפסים: פריטים, סעיפים, מטריצה. לשינוי נוסח עורכים רק כאן
js/model.js           בונה "מודל מסמך" אחד מהדוח
js/render-html.js     מודל → תצוגה מקדימה (HTML)
js/export-pdf.js      מודל → PDF (jsPDF + bidi + גופן עברי מוטמע)
js/export-docx.js     מודל → Word (ספריית docx)
js/app.js             ממשק, ניווט, שמירה אוטומטית
js/db.js              אחסון מקומי + גיבוי
js/signature.js       משטח חתימה
sw.js                 עבודה אופליין
vendor/               ספריות צד שלישי (docx, jsPDF, bidi-js, גופן Liberation Sans, רישיון OFL)
```

כל שלושת הפורמטים (תצוגה, PDF ו-Word) נבנים מאותו מודל, ולכן התוכן שלהם תמיד זהה.
